# Shelf for Xbox

Your media library on an Xbox in Developer Mode: books, comics and manga, audiobooks, music, podcasts, movies,
photos, retro games and live TV.

Everything is kept in **`D:\DevelopmentFiles\Shelf`**, one folder per kind (Books, Comics, Manga, Audiobooks,
Music, Podcasts, Movies, Photos, Games, Recordings, plus Saves and Data). Add files with Device Portal's
**File explorer → DevelopmentFiles → Shelf**.

## Install

1. Download the latest zip from **Releases** and unzip it on your PC.
2. Open Device Portal (the address shown in Dev Home on the Xbox) → **Add**.
3. Choose the `.msix`, tick **Allow me to select framework packages**, and add the files from `Dependencies`.
4. Start Shelf from Dev Home / My games & apps.

## Status

Every file is its own item in the library: each song, podcast episode, photo, and each part of a multi-file audiobook.

First build: library and folders, movies / music / podcasts / audiobooks, photos. Readers, phone uploads, live TV and
built-in emulators come next.
